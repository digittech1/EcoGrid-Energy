# Suggested team workflow

1. Create a Monday.com task with owner and acceptance criteria.
2. Create a GitHub issue referencing the task.
3. Work on a branch named `feature/<short-description>`.
4. Commit changes with descriptive messages.
5. Open a pull request and request peer review.
6. Run GitHub Actions tests; resolve failures.
7. Merge approved changes and update the project board.

## Evidence to capture after actual work
- GitHub repository file list
- Commit history showing genuine author contributions
- Pull request with real review discussion
- Monday.com task board showing genuine assignments
- Team communication evidence, with private information removed

Do not represent this suggested workflow or sample files as completed team activity.
